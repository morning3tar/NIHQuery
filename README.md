# NIHQuery
![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)

A Telegram bot to quickly retrieve NIH funding information (grants) for Principal Investigators using the official NIH RePORTER API.

## Features 

* **Search by PI Name:** Simply send the bot the full name of a Principal Investigator.
* **Detailed Grant Info:** Displays key details for each grant found:
    * Project Title
    * Application ID
    * Principal Investigators
    * Awardee Organization
    * Total Funding Amount
    * Direct Costs
    * Indirect Costs
    * Fiscal Year
